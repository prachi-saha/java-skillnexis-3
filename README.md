# Java Exception and File Handling Programs

This repository contains Java programs based on Exception Handling and File Handling concepts.

## Programs Included

1. **divbyzero.java** – Handles divide-by-zero exceptions using try-catch.
2. **file.java** – Demonstrates reading and writing text files.
3. **multiple.java** – Demonstrates multiple catch blocks in Java.
4. **invalidage.java** – Creates a custom exception for invalid age input.
5. **wordcount.java** – Counts the number of words in a text file.

## Concepts Covered

- Exception Handling
- Try-Catch
- Multiple Catch Blocks
- User-Defined Exceptions
- Throw Keyword
- File Handling
- FileReader and FileWriter
- Reading and Writing Text Files

## Language Used
Java

## Purpose
To understand and practise exception handling and file handling concepts in Java.
